# Diabetes Prediction Using Machine Learning

A machine learning classification project developed to analyze diabetes-related health data and predict diabetes outcomes using multiple classification algorithms.

## Project Overview

This project applies a complete machine learning workflow to a diabetes dataset, including data exploration, preprocessing, model training, prediction, and performance evaluation.

The objective is to explore how machine learning classification techniques can be applied to health-related data for diabetes prediction.

## Dataset

The project uses the `diabetes.csv` dataset containing health-related attributes used for diabetes classification.

## Machine Learning Workflow

The project includes:

- Loading and exploring the dataset
- Checking and preparing the data
- Data preprocessing
- Splitting the dataset into training and testing sets
- Training multiple classification models
- Generating predictions
- Evaluating and comparing model performance

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Files

- `Final_Project_ML.ipynb` — Main machine learning notebook containing the analysis, preprocessing, model training, and evaluation.
- `diabetes.csv` — Dataset used in the project.
- `.gitignore` — Specifies files and folders that Git should ignore.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `Final_Project_ML.ipynb` using Jupyter Notebook or JupyterLab.
4. Run the notebook cells in order.

## Purpose

This academic project was developed to practice the end-to-end machine learning process, from preparing a dataset to training and evaluating classification models.
